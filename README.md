 Bank Customer Churn Prediction and Risk Analysis

Project Overview

This project focuses on analysing customer churn in the banking sector to identify customer exit patterns, understand risk factors, and develop strategies to improve customer retention.

Project Objective

- Analyse customer churn behaviour.
- Identify customer segments with higher churn rates.
- Examine customer characteristics and account-related factors.
- Provide data-driven recommendations to improve customer retention.

Tools Used

- Microsoft Excel – Data cleaning, calculations and analysis.
- Power BI – Interactive dashboard and data visualisation.
- Python – Data analysis (if included in the project).

Project Workflow

1. Data collection and understanding.
2. Data cleaning and preparation.
3. Exploratory data analysis.
4. Customer churn rate calculation.
5. Dashboard creation.
6. Insights and recommendations.

Key Business Focus

- Customer retention
- Churn rate analysis
- Customer segmentation
- Banking risk analysis
